Amplitude x Airbridge (Web) 연동 데모

MMP(Airbridge) 어트리뷰션을 Amplitude 로 연결. 핵심은 Amplitude device_id 를 Airbridge device alias 로 매칭하는 것.

1. 설정 (대시보드에서 발급)

초기화 순서: Amplitude init(await) → device_id 획득 → Airbridge init(autoStart off) → setDeviceAlias → startTracking

2. 식별자 상태

진입 채널 (referrer)
-
Amplitude device_id
-
Airbridge alias
-
Amplitude user_id
-
초기화
아직 안 함

3. 어트리뷰션 확인 - 이벤트 전송

Airbridge 이벤트를 보내면 V2 연동으로 Amplitude 에 어트리뷰션(User Property)과 함께 전달됩니다.
